# 跨性別檔案館 (Transgender Archive Taiwan)

## 關於此專案
本專案彙整台灣跨性別族群相關的公開資訊，內容包含社群連結、醫療資源、書籍手冊、法律文件及其他相關網站的集中存取。

## 內容分類
- **🌐 網站**：收錄台灣本地跨性別組織及相關資訊網站
- **👥 社群**：整理各平台討論區與交流群組
- **🔗 資源**：提供醫療資源清單、RLE、HRT、SRS 相關資訊
- **📄 文件**：整理政府公文、書籍手冊、研究報告、法律判決

## 注意事項
- 本專案僅收集並整理公開網址，不直接存放 PDF、Word、影像檔案
- 所有收錄之連結皆以公開可存取為原則，避免提供需帳號或付費才能查看的資源
- 若原始連結失效或遭移除，將透過 Internet Archive (Wayback Machine) 或其他網頁備份服務提供內容
- 本專案僅供資訊參考使用，使用相關醫療或法律資訊前，請務必諮詢專業人士或官方機構
